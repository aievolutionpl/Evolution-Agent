# Script, Scenario & Storyboard Development

The agent should not jump directly from idea to final Seedance prompt when the concept needs story structure.

## Script-first situations

Write a scenario first when the request contains:

- several events
- dialogue
- advertising message
- transformation
- before / after
- reveal
- joke / punchline
- product demonstration
- emotional arc
- several locations
- 15–30 second narrative

## The one-sentence spine

Before shots, define the whole video in one sentence:

```text
A [subject] moves from [starting state] to [payoff] through [main visual action], so the viewer understands / feels [intended result].
```

Example:

```text
An unfinished fireplace room becomes a complete warm living space through one team's craft, so the viewer understands they can handle the entire transformation.
```

If the one-sentence spine is unclear, the video is not ready for shot design.

## Script layers

Build only the layers the job needs.

### Story layer

```text
setup
trigger
progression
payoff
```

### Advertising layer

```text
hook
problem / desire
proof / demonstration
benefit
hero / result
CTA handoff
```

### Social layer

```text
first-frame hook
curiosity / tension
escalation
payoff
loop / clean end
```

## Beat writing

Each beat should contain one dominant visible change.

Use:

```text
BEAT NAME
Purpose:
Visible action:
New information:
End state:
```

Do not write abstract beats such as "feels more premium".

Convert them into visible changes.

## End-state rule

An end state must be observable.

Weak:

```text
He feels powerful.
```

Strong:

```text
His shoulders settle, helmet closes, both feet are planted and he faces camera.
```

## Storyboard design

For each storyboard panel decide:

```text
shot purpose
shot size
angle
subject position
action
camera move or static choice
light direction
transition logic
end state
```

## Coverage rule

Do not create extra angles just to look "professional".

A new shot should do at least one of these:

- reveal information
- show proof
- change emotional distance
- clarify an interaction
- establish scale
- isolate product detail
- improve the payoff

## Scenario density

Keep event density plausible.

### 5–8 seconds
Usually 2–3 beats.

### 8–15 seconds
Usually 3–5 beats.

### 15–30 seconds
Usually 4–8 beats, depending on dialogue and action complexity.

These are directing heuristics, not provider limits.

## Dialogue script format

```text
CHARACTER A
Intent: what they want in this moment
Performance: visible body / facial behaviour
Line: "..."

CHARACTER B
Intent: ...
Performance: ...
Line: "..."
```

Keep lines conversational and speakable inside the allocated time.

## Advertising scenario example

```text
SPINE
A homeowner sees the unfinished fireplace area, watches one team complete the surrounding work, then sees the final room.

BEAT 1 — PROBLEM
Wide reveal of unfinished wall.
End state: unfinished work is obvious.

BEAT 2 — PROOF
Tradesperson physically plasters the wall.
End state: craft is believable.

BEAT 3 — TRANSITION
Worker passes close to camera and occludes frame.
End state: cut is motivated.

BEAT 4 — RESULT
Same room, finished and styled.
End state: portfolio hero frame.
```

Only after this structure works should the agent convert it into the production prompt.

## Script humanizer

Avoid generic ad dialogue and generic movie lines.

Reject phrases like:

- "The future is here"
- "Experience innovation like never before"
- "Unlock the power of..."
- "This changes everything"

unless the user explicitly requests that tone.

Prefer concrete human language, observable situations and product truth.

## Final scenario rule

**A prompt describes how to shoot the story. The scenario decides what story is worth shooting.**
