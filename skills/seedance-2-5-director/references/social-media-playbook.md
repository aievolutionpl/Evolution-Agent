# Social Media Video Playbook

Use this for Reels, TikTok, YouTube Shorts, paid social and creator-style short-form video.

## Social video is not just vertical cinema

A social video must solve four things quickly:

1. stop the scroll
2. make the premise understandable
3. keep visual progression clear
4. land a payoff / result / reason to act

## Default format logic

If the user clearly wants Reels / TikTok / Shorts and gives no ratio:

```text
9:16 vertical
```

Keep critical subjects and product information inside vertical-safe framing.

## First-frame test

The opening frame should work as a still.

It needs at least one:

- visual surprise
- strong product detail
- recognizable person / face
- clear problem state
- unusual scale
- transformation already beginning
- visually readable action

Avoid spending the first seconds on generic drone establishing shots unless the location itself is the hook.

## Hook categories

### Visual contradiction
Something looks wrong / impossible but readable.

### Outcome first
Show the finished result, then reveal how it happened.

### Texture / detail
Macro food, material, skin, product, machine movement.

### Action already in progress
Start during the moment, not before preparation.

### POV / entrance
Viewer immediately enters the situation.

### Human reaction
Readable face / body response creates curiosity.

## Beat pacing

For many 8–15 second videos:

```text
HOOK
→ DEVELOPMENT
→ ESCALATION / PROOF
→ PAYOFF
→ CLEAN END
```

3–5 meaningful beats are usually stronger than constant cuts.

A useful heuristic is a perspective or information change every ~2–3 seconds when it actually improves retention.

Do not force this if a continuous shot is stronger.

## Retention rule

Each new beat should answer one question and create the next.

Example:

```text
What is this?
→ What is happening?
→ Can it actually work?
→ What is the result?
```

## Camera for social

Use movement with high readability.

Good:

- close push-in
- subject-speed tracking
- foreground reveal
- macro slide
- quick but controlled reframing
- motivated whip cut
- POV move through a doorway / portal

Avoid:

- huge orbits that lose the subject
- slow cinematic movement that delays the hook
- random angle changes
- over-wide framing where the product or face becomes tiny

## Social humanizer

Creator / UGC style should not look like a polished perfume campaign unless requested.

Useful cues:

- slightly imperfect handheld phone framing
- natural reaction timing
- small exposure shift when moving between spaces
- believable creator eye line
- conversational delivery
- short pauses
- natural hand demonstration

Do not intentionally create low-quality anatomy, audio or unreadable product detail.

## Social commercial structure

For ads:

```text
HOOK
PROBLEM / DESIRE
PRODUCT OR SERVICE PROOF
RESULT
CTA HANDOFF
```

The generated video does not need to render precise CTA typography. Leave clean negative space or a stable final frame for post-production copy when exact text matters.

## Before / after

For services, renovation, beauty, cleaning, fitness, restoration:

- preserve camera position or architecture when comparison matters
- motivate transformation with action / occlusion / match cut
- keep the before state readable long enough to understand
- make the after state clean and settled

## Food social

Prioritize:

- texture
- heat / steam when physically plausible
- ingredient structure
- contact sounds
- one satisfying interaction
- final hero frame

Do not use floating ingredients by default.

## Product social

Prioritize:

- immediate product readability
- one core benefit or interaction
- exact product geometry
- tactile sound
- controlled reflections
- clean final frame

## Viral without slop

"Viral" is not an instruction.

Translate it into:

```text
unexpected but readable hook
fast premise recognition
one strong escalation
memorable payoff
shareable visual idea
```

Avoid random chaos, meme overlays or exaggerated reactions unless they are actually part of the concept.

## Loop design

If a loop helps:

- end in a composition that can visually connect to the first frame
- use repeated motion direction
- match shape / camera position
- do not force a loop if it weakens the payoff

## Social output contract

When the user asks for a full social concept, the agent may return:

1. concept / hook
2. short scenario
3. shot timeline
4. Seedance prompt
5. audio / music plan
6. suggested overlay copy for editing, kept outside the generated video prompt when precision matters

If the user requests prompt only, return prompt only.
