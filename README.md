## English

### What is this project?
Hermes is a business-focused AI agent workspace from AI Evolution Labs. It helps teams run repeatable work with AI agents, including reporting, research, operations, and delivery support.

### Key capabilities
- Multi-agent workflows (planning, execution, review, QA).
- Business shortcuts for common operational tasks.
- Integrations with tools, files, terminal workflows, and automation patterns.
- Dashboard-oriented workflow for visibility and faster execution.

### Tech stack
- React 19 + Vite
- TypeScript
- Electron support
- Vitest + ESLint + Prettier

### Quick start
#### Requirements
- Node.js 22+
- pnpm

#### Install
```bash
pnpm install
```

#### Run in development
```bash
pnpm dev
```

#### Run app + gateway together
```bash
pnpm start:all
```

#### Build
```bash
pnpm build
```

#### Test
```bash
pnpm test
```

### Useful scripts
- `pnpm lint` — run ESLint.
- `pnpm check` — format and fix lint issues.
- `pnpm preview` — preview production build.
- `pnpm electron:dev` — run desktop app in development mode.

## Polski

### Czym jest ten projekt?
Hermes to biznesowy workspace agentów AI od AI Evolution Labs. Pomaga zespołom wykonywać powtarzalną pracę z użyciem agentów AI: raportowanie, research, operacje i wsparcie realizacji.

### Najważniejsze możliwości
- Workflow wieloagentowy (planowanie, wykonanie, review, QA).
- Skróty biznesowe do najczęstszych zadań operacyjnych.
- Integracje z narzędziami, plikami, terminalem i automatyzacjami.
- Praca w modelu dashboardowym dla lepszej widoczności i szybszego działania.

- TypeScript
