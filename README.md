## 🇵🇱 Wersja polska

### Czym jest Hermes Evolution Agent?

**Hermes Evolution Agent** to rozwijany przez **AI Evolution Labs** fork/nakładka na ekosystem Hermes: dostajesz znany fundament agenta, ale z naszym **custom dashboardem biznesowym**, dodatkowymi **skillsami**, operacjami wieloagentowymi i gotowymi przepływami pracy dla firmy.

To nie jest zwykły "chat z AI". To operacyjne centrum firmy, w którym agent robi realną pracę: od sprzedaży, przez raportowanie, po automatyzacje i research.

### Co dokładnie zostało ulepszone względem bazowego Hermesa?

- **Dashboard pod biznes**: sesje, koszty, modele, operacje, biblioteka skillsów w jednym miejscu.
- **Gotowe skróty biznesowe**: uruchamiasz zadanie jednym kliknięciem, bez dłubania w promptach.
- **Silniejszy workflow**: Conductor + Swarm + role agentów (builder/reviewer/qa/researcher itd.).
- **Integracje i narzędzia**: MCP, terminal, pliki, memory, automatyzacje.
- **Lepszy onboarding**: prosty start, instalacja i szybkie przejście do działania.

### Przykłady zastosowań (PL)

1. **Sprzedaż** – oferta + mail + zakres wdrożenia dla nowego klienta.
2. **Zarząd** – tygodniowy raport KPI z podsumowaniem ryzyk i rekomendacjami.
3. **Marketing** – seria postów, plan publikacji i warianty komunikatów.
4. **Operacje** – automatyczne checklisty, taski i przypomnienia cykliczne.
5. **Finanse** – porównanie kosztów narzędzi, alerty anomalii, raport miesięczny.
6. **HR** – opis stanowiska, screening CV, shortlista kandydatów.
7. **Compliance** – porównanie dokumentów (np. NDA) i wskazanie ryzyk.
8. **Research** – monitoring konkurencji i tabela zmian produktowych.

### Dla kogo to jest?

Dla founderów, zespołów sprzedaży, operacji, marketingu, finansów i customer success, które chcą mieć **Hermesa dla biznesu** — praktycznego, szybkiego i gotowego do codziennej pracy.

## 🇬🇧 English version

### What is Hermes Evolution Agent?

**Hermes Evolution Agent** is AI Evolution Labs’ business-focused fork/layer on top of the Hermes ecosystem: you keep the proven agent core, then gain our **custom business dashboard**, expanded **skills library**, multi-agent operations, and production-ready workflows.

This is not just an AI chat wrapper. It is an execution cockpit where agents do real work across sales, operations, reporting, research, and automation.

### What is improved vs base Hermes?

- **Business-first dashboard**: sessions, costs, model mix, ops, and skills in one place.
- **One-click business shortcuts**: launch high-value tasks without prompt engineering.
- **Stronger execution system**: Conductor + Swarm + role-based agents.
- **Tooling depth**: MCP integrations, terminal, files, memory, and automation support.
- **Simpler onboarding**: faster install and a cleaner path to first business outcome.

### Example business outcomes (EN)

1. **Sales** – proposal pack + outreach email + implementation scope.
2. **Leadership** – weekly KPI brief with risk flags and next actions.
3. **Marketing** – campaign posts, publishing plan, and message variants.
4. **Operations** – recurring checklists, assignments, and auto-reminders.
5. **Finance** – tooling cost analysis, anomaly detection, monthly report draft.
6. **HR** – role spec, CV triage, and ranked candidate shortlist.
7. **Compliance** – contract diffing (e.g., NDA) with risk annotations.
8. **Research** – competitor monitoring with feature/pricing delta tables.

### Who is it for?

Teams that need a **business-grade Hermes**: founders, sales, ops, marketing, finance, and customer success teams that want AI agents to ship outcomes, not just responses.

## 🚀 Quick start · Szybki start

### 🇬🇧 How to run it — pick one path. All take **2 minutes or less**.

### 🇵🇱 Jak to uruchomić — wybierz jedną ścieżkę. Każda **trwa maks. 2 minuty**.

---

### Path 1 — One-line install (macOS / Linux) · Instalator jednolinijkowy

```bash
curl -fsSL https://raw.githubusercontent.com/aievolutionpl/Evolution-Agent/main/install.sh | bash
```

**🇬🇧** Clones the repo, sets up `.env`, installs deps. Then:
**🇵🇱** Klonuje repo, tworzy `.env`, instaluje zależności. Następnie:

```bash
cd Evolution-Agent
pnpm dev
```

Open **[http://localhost:3000](http://localhost:3000)** — the welcome tour opens in your language.
Otwórz **[http://localhost:3000](http://localhost:3000)** — pojawi się powitanie w Twoim języku.

---

### Path 2 — Docker Compose

```bash
git clone https://github.com/aievolutionpl/Evolution-Agent.git
cd Evolution-Agent
cp .env.example .env
docker compose up -d
```

**🇬🇧** Pulls pre-built images. Open **[http://localhost:3000](http://localhost:3000)**.
**🇵🇱** Pobiera obrazy. Wchodzisz na **[http://localhost:3000](http://localhost:3000)**.

---

### Path 3 — Local dev · Tryb deweloperski

```bash
git clone https://github.com/aievolutionpl/Evolution-Agent.git
cd Evolution-Agent
pnpm install
cp .env.example .env
pnpm dev
```

> 💡 **Tip / Wskazówka:** set `HERMES_API_URL` in `.env` if your `hermes-agent` runs somewhere other than `http://127.0.0.1:8642`.
> 💡 Ustaw `HERMES_API_URL` w `.env`, jeśli `hermes-agent` działa pod innym adresem niż `http://127.0.0.1:8642`.

## 📦 Install as a desktop app · Instalacja jako aplikacja desktopowa

### Install as PWA (any platform, 1 click) · Instalacja PWA (1 klik)

1. Open **[http://localhost:3000](http://localhost:3000)** in Chrome / Edge / Safari
2. Click the **install icon** in the address bar
3. Lands on your desktop with the **AI Evolution Labs gold mark**
4. Launches as a standalone window — no browser chrome

**🇵🇱** Otwórz adres w Chrome/Edge/Safari → kliknij ikonę instalacji → skrót ląduje na pulpicie ze **złotym znakiem AI Evolution Labs**.

### Build as native Electron app · Buduj natywną apkę

```bash
pnpm electron:build:mac      # → release/Hermes Evolution Agent-3.0.0.dmg
pnpm electron:build:win      # → release/Hermes Evolution Agent Setup 3.0.0.exe
```

## 🧱 Architecture · Architektura

```
┌───────────────────────────────────────────────────────────────┐
│           Hermes by AI Evolution Labs (this repo)             │
│                                                                │
│   Chat · Dashboard · Conductor · Swarm · Skills · MCP · …     │
│   AIEL brand · Business shortcuts · Bilingual onboarding      │
└───────────────────────────────────────────────────────────────┘
                              │
                              ▼ HTTP / WS
┌───────────────────────────────────────────────────────────────┐
│            hermes-agent (Nous Research — vanilla)             │
│                                                                │
│   Gateway · Sessions · Memory · Skills · Tools · MCP runtime  │
└───────────────────────────────────────────────────────────────┘
                              │
                              ▼ OpenAI-compatible API
┌───────────────────────────────────────────────────────────────┐
│      Your LLM (OpenAI · Anthropic · Google · OpenRouter)      │
└───────────────────────────────────────────────────────────────┘
```

**🇬🇧** Hermes is a **zero-fork workspace** on top of vanilla [`hermes-agent`](https://github.com/NousResearch/hermes-agent) by Nous Research. We don't patch the runtime — we wrap it with a business-first UI, brand identity, shortcuts, multilingual onboarding, and integrations.

**🇵🇱** Hermes to **workspace bez forka** — nakładka na waniliowy [`hermes-agent`](https://github.com/NousResearch/hermes-agent) od Nous Research. Nie patchujemy runtime'u — opakowujemy go w biznesowe UI, brand, skróty, lokalizację i integracje.
